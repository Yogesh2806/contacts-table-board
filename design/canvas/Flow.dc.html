Panel rules
• Side peek on the right: pushes the list at 1280px and up, overlays it below.
• Tab order inside: Stage → Notes → Cancel → Save changes.
• J / K walk to the previous or next record; a dirty draft asks first.
• After Save the panel stays open on the saved record.
• Esc or close returns focus to the row or card, even if the card moved column.
1 · Source of truth
contacts: one list, keyed by id, changed only by a reducer action updateContact(id, patch).
2 · Derived, never copied
Table rows and board groups are computed from contacts on every render. No second copy means no duplicate or stale card.
3 · UI state, kept per view
view, selectedId, draft, scroll position per view and the element that opened the panel — so closing puts you back.
