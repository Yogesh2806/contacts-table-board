Step 1 · Real-world patterns

Borrow what people already know

Familiar patterns cost users nothing to learn. For each product: the pattern, what we take, and where we deliberately differ.

TableBoard

Notion databases

View tabs over one data source · side peek
Take: Table and Board as tabs on the same data. Opening a record in a side peek, so the list stays visible behind it.
Differ: Notion autosaves. The brief asks for a clear Save and Cancel, so edits are a draft until you commit.

Linear

Keyboard-first · calm density
Take: Every action has a key. J and K walk records with the panel open; ⌘↵ saves; Esc backs out one level at a time.
Differ: We show shortcuts in tooltips and button labels, so nobody has to memorise them first.

Take: Owners as avatar plus name, quiet black-and-white chrome, and colour only where it means something. That is Aa NAD's rule too.

Pipedrive and HubSpot deal boards

Stages left to right · counts per column
Take: Stages read left to right in the order a deal moves. Each column header shows a live count.
Differ: An empty column keeps its full height with a hint, so it is still a visible target.

Airtable

Frozen primary column · expanded record
Take: The Name column stays frozen while the rest scrolls sideways. That is our answer to the narrow desktop.
Differ: Fewer columns by default. Notes collapse into a one-line preview.

Gmail

“Archived · Undo” toast
Take: After a save, a toast says what changed in plain words, with Undo. Saving feels safe because it is reversible.
Differ: Focus never jumps to the toast. It is announced politely to screen readers.
