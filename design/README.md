# Design sources

- `tokens.json`: design tokens (colour with light and dark values, type, spacing, radius, shadows, layout, motion). Generated from `src/styles/tokens.css`.
- `COMPONENTS.md`: the component inventory: what is reusable, with its variants and properties.
- `canvas/`: the original design canvas (problem breakdown, field map, flows, Nielsen's heuristics and screens A–K) as HTML. These files load an Aa NAD component bundle that isn't included here, so open them as references; the live app is the rendered result.

The plan for rebuilding these designs as an editable Figma file is in `../FIGMA-HANDOFF.md`.
